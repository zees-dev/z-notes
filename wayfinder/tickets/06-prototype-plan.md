## Question

How should the themed UI prototypes be delivered and which themes should be built?

## Resolution

**Self-contained HTML files under `prototypes/` in this repo, local only** — opened directly in a browser, nothing published externally. Six themes:

1. Modern
2. Minimalistic
3. Cyberpunk / futuristic
4. Terminal / TUI
5. Glassmorphism dark
6. Notion warm/paper

Each mockup uses dummy markdown content from the user's domain (keys, architecture notes, side projects) and must demonstrate: sidebar folder tree, block-style editor, `[[doc-links]]`, a secret block (locked/unlocked), settings view, AI chat pane with a proposed-diff accept/revert flow, density toggle (compact/comfy), and mobile-responsive layout.

Decided with z during charting, 2026-07-31.
